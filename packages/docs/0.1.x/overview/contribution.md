# Contribution Guidelines

Thank you for considering contributing to Sodium, our Marketplace generator! We're excited to have you on board and look forward to your contributions. Here are the guidelines you should follow to make the contribution process smooth and effective.

## Getting Started

1. **Environment Setup**: Make sure you have followed the [Getting Started](0.1.x/overview/getting-started.md) guide to set up your environment correctly for Sodium.
2. **SECRETS_ENCRYPTION_KEY_DEV**: Obtain this key from your team to run the Sodium backend locally.

## Contribution Process

1. **Fork and Clone**: Fork the Sodium repository and clone it to your local machine.
2. **Branching**: Create a new branch for each set of changes you intend to make in Sodium. Use a clear and descriptive name for your branch.

## Code Guidelines

1. **Code Style**: Adhere to the coding standards set for Sodium. Utilize Prettier and ESLint to ensure consistency.
2. **Comments**: Write meaningful comments to clarify complex logic or important decisions in the code.
3. **Documentation**: Update the documentation if your changes are significant or if you introduce new features to Sodium.

## Making Changes

1. **Small Commits**: Commit small, incremental changes with clear descriptions of what has been modified.
2. **Testing**: Add tests for your changes to ensure reliability and prevent regressions within Sodium.
3. **Self-Review**: Review your own changes before submitting a pull request. Check for any unnecessary or commented-out code.

## Pull Requests

1. **Title and Description**: Provide a descriptive title and a detailed description for your pull request. If applicable, link to related issues or discussions.
2. **Pull Request Reviews**: Be responsive to feedback on your pull request. Each pull request should be reviewed by at least one other developer.

## Technologies and Frameworks

- Familiarize yourself with the technologies used in Sodium, such as React, React Native, Next.js, TypeScript, tRPC, React Query, GOT, and Tailwind CSS.
- Contributions to the mobile sector should align with the React Native Expo app standards.
- Backend contributions should comply with the Express and TRPC framework standards within Sodium.

## Community and Conduct

- Be respectful and considerate in your interactions with other contributors to Sodium.
- Adhere to the project's code of conduct to maintain a welcoming and inclusive environment for all contributors.

## Asking for Help

If you encounter any issues or have questions while contributing to Sodium, don't hesitate to ask for help. Our team is here to assist and support each other.

We appreciate your contributions to Sodium and look forward to seeing your impactful work. Let's make Sodium even better, together!
