# Overview

## Before You Start

Obtain the SECRETS_ENCRYPTION_KEY_DEV environment variable from your team; it's
crucial for the backend operation.

## The Project

This project leverages pnpm and Turborepo. Refer to the "Getting Started"
section for setup instructions. The repository contains:

- **Backend**: An Express and TRPC backend.
- **Frontend**: A Next.js application interfacing with the TRPC backend.
- **Mobile**: A React Native Expo app connected to the TRPC backend.
- **Commerce**: Enhanced Wordpress & Woocommerce integration.
- **Infrastructure**: Managed GCP and local environments with Pulumi.
